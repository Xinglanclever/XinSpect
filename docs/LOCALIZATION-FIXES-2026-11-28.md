# 2026-11-28 語言殘留修復與本地 AI 範圍變更

## 使用者指示

取消本輪新增的真實本地 AI／模型推論；保留既有 NPU 識別與明確標為 CPU 的 SIMD 基準。簡體中文及英語的繁體殘留屬本輪必修，不以零散替換文字作完成判斷。本文件不代表發布或全平台硬體驗收。

## 已確認根因與修正範圍

- 原語言切換只遍歷主視窗，獨立視窗與稍後載入內容未共用生命週期。新增 WPF 顯示橋接，涵蓋視窗標題、行內文字、選單、工具提示及表格欄標頭。
- 原本為保留 Binding 而完全略過綁定文字；動態數據與狀態未可靠隨語言更新。新路徑保留 Binding、converter、StringFormat，監看顯示目標，於來源更新及語言切換重新投影。可回寫來源的綁定不得藉翻譯改動來源。
- 原文槽只記第一次內容，稍後重新指定狀態可能被舊內容覆蓋。現在分開保存原文與最近輸出，僅在實際內容改變時更新原文。
- 舊 bool 切換入口未清除英文旗標；已統一委派互斥語言入口。啟動時的單例提示以只讀語言偏好處理，不能因此建構硬體路由。
- 英文精確詞庫缺項，插值後整句查表也會失敗。擴充詞庫並支援已收錄格式模板；參數、數值格式、硬體名稱、路徑及使用者文字須保留。
- 唯讀文字框須明確使用 IsUiText，僅翻譯已知產品說明；終端輸出、原始 JSON、IPC、日誌與使用者內容不自動轉寫。自繪控制項需在繪圖邊界本地化，並隨語言切換重繪。

## 取消功能的處理

本輪新增的 11 個 LocalInference 正式檔案、NPU 頁新入口及 Microsoft.ML.OnnxRuntime.DirectML 套件引用已移除。保留 work 內既有調查／失敗證據，不將其打包為產品功能。SIMD 的 FLOP 計數與不重疊輸出區段修正獨立保留。

保留每輪編譯失敗、實際 TRX 與畫面快照。檢查包含繁中→簡中→英語→繁中重複循環、英文模式新開視窗、後載入與動態文字、原始 Binding／converter 存活、雙向來源不變、原始資料保留及卸載後退訂。
