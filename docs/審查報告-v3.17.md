## P2 · 錯誤判決 / 安全缺陷

23. **XtuBridge SDK 路徑 DLL 注入面**〔代理〕
    `Bridge/XtuCore.cs:1005-1015、119` — SDK 路徑取自使用者可寫的 `%APPDATA%\XinSpect\Overclock\xtu_path.txt`，`Assembly.LoadFrom` 無簽章/雜湊驗證；AssemblyResolve（:104-117）可從 probe 目錄載入任意 DLL。低權限進程可注入 ring0 相鄰的提權橋接。

    `BlueSquadron/WmiSecurityReader.cs:43` 把 Win32_DeviceGuard 屬性 1（VT-x）當 IOMMU；主程式 SecurityPostureService.cs:751-778 已知錯並改用 ACPI DMAR/IVRS——Bridge 端沒同步。DMA 攻擊面被虛假綠燈掩蓋。

25. **MSR 快照 per-CPU 基線錯誤 → 假警報**〔本人〕
    `BlueSquadron/Driver/MsrSnapshot.c:51-91` — DPC 在任意 CPU 執行，`__readmsr` 讀當前核，基線是全域單份；SPEC_CTRL/FEATURE_CONTROL 逐核合法不同 → `BsSevCritical` 假警報。另：讀不到的 MSR 以 -1 進基線（暫時例外毒化基線）。

26. **LSASS 保護：DUPLICATE 路徑裸奔**〔本人〕
    `BlueSquadron/Driver/BlueSquadronDriver.c:140` 註冊 CREATE|DUPLICATE，`Callbacks.c:139` 只剝 CREATE——既有完整權限句柄可無限複製傳播。

27. **超頻 apply 靜默零**〔本人〕
    `Bridge/Program.cs:208-234` — `U32`/`Dbl` 解析失敗回 0；`apply` 的 value 缺失即 `core.Apply(id, 0, …)` 寫入硬體。
