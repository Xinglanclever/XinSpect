# 曦覽 XinSpect 3.10「Ultima XII」

總覽改成「先看清楚這台機器是什麼」：三顆膠囊 ＋ 一張詳細資訊清單，即時儀錶盤預設收起。

## 這一版做了什麼

### 總覽：膠囊摘要 ＋ 詳細資訊

進站第一眼不再是四顆跳動的圓形儀表，而是這台機器本身：

- **三顆膠囊**：機型資訊（整機廠商與型號）、系統資訊（作業系統與版本）、已運行時間（開機至今）。
- **詳細資訊**：主機板、處理器、記憶體、顯示卡、顯示器、硬碟、聲卡、網卡各一列，一列可以有多筆裝置。
  內容全部取自開機時已讀好的系統摘要（SMBIOS／WMI／磁碟列舉／EDID），**這一頁不另外掃描**，
  不會為了畫一張摘要卡去等 WMI。
- **即時儀表、即時走勢與七段數字面板改為預設關閉**。它們每秒在跳，卻不是多數人打開這個程式的原因；
  要看的到「自訂磁貼」勾一下就有，版面會記住。已經存過版面的使用者不受影響——**存檔優先於內建預設**。
- 新增兩個介面元件：`CapsuleCard`（圓角 16 的半徑才像膠囊，不是一般卡片）與 `InfoRow`
  （值是任意內容，所以一列可以放一串裝置）。中文格式字串走既有的 `LangFormatConverter`，
  英語與簡體模式才跟得上。

### 處理器頁：多一列「微架構」

處理器頁「規格」新增 **微架構**：`Golden Cove`、`Cypress Cove`、`Zen 4`……混合架構寫成
**`Raptor Cove（P 核）＋ Gracemont（E 核）`**——同一個 model 兩種核心，只報大核等於只講一半。
核型取自 CPUID 0x1A；畫面用的短版與事實層共用同一個判斷，不會各寫一份。

「微架構」與「行銷世代」不是同一件事：同一個世代可能有兩種核心（P 核與 E 核），同一種核心
也橫跨好幾代（Skylake 核心從 6 代一路用到 10 代）。要判斷暫存器佈局需要的是前者。

### 新增事實鍵 `cpu.uarch`

由 CPUID 的廠商字串 ＋ family／model 判斷微架構：

- **Intel 走既有的 `MicroarchProfile`**：它與 TMA 分母、超頻的 VF 參考線是同一份事實，也分得出大小核。
- **其餘（AMD、Hygon、舊世代）走 `CpuUarchTable`**：pytorch/cpuinfo 的 `src/x86/uarch.c` 逐格搬過來
  （BSD-2，已列進 `THIRD-PARTY-NOTICES.md`）。
- 為什麼不是只搬 cpuinfo：**它最新幾格是伺服器優先**（0x8F／0xCF／0xAD），桌機的 0x97／0xB7／0xBA／0xAA
  與 Rocket Lake 的 0xA7 根本沒有 case——照抄會讓一台 i5-13600K 顯示「未收錄」。

### 順帶修掉一個整代標錯

世代表把 **0x97 當成 Rocket Lake**，而 0x97 是 Alder Lake-S（i5-12600K 的簽章是 6／151／2），
Rocket Lake 是 0xA7（i7-11700K 是 6／167／1）。也就是說：**所有第 12 代 Core 桌機都被標成第 11 代**。
這件事是靠「世代表與微架構表對同一顆 CPU 給出不同答案」才現形的，現在兩張表钉在同一條測試上。

### 百科內文跟著外殼換深色

舊版在淺色系統上會出現「深色工具列、白色內文」的割裂。現在程式內建文件固定使用深色樣式；
用一般瀏覽器開同一個檔案時，仍照瀏覽器的設定走。

  沒有 Content-Length 也收得到。
