# 曦覽 XinSpect 3.11 測試版「Swiss／Helvetica 實驗」

> **這是實驗版，不是正式版本。** 介面換成瑞士現代主義（International Typographic Style）的語彙，
> 字體換成 Helvetica。合用就留下，不合用整支丟棄——它跑在 `experiment/swiss-helvetica` 分支，
> `main` 沒有被動到，正式版仍然是 3.10。

## 這一版改了什麼

### 字體：Helvetica

拉丁字母與數字走 **Helvetica**；機器上沒有 Helvetica 時退到 **Arial**（它是 Helvetica 的公制克隆，
換行與字寬不會跑掉）。中日韓字仍由 **Microsoft JhengHei UI** 承接——Helvetica 本身沒有漢字，
這不是取捨，而是字型本身的能力邊界。

### 配色：白紙、黑墨、髮絲線、一道紅

| 角色 | 值 | 說明 |
|---|---|---|
| 紙面 | `#FFFFFF` | 純白，不是暖白 |
| 主墨 | `#000000` | 正文與標題 |
| 次墨 | `#1F1F1F` | 約 16:1 對比 |
| 弱墨 | `#6B6B6B` | 仍高於 WCAG AA 的 4.5:1 |
| 髮絲線 | `#D0D0D0` | 結構線取代陰影 |
| 強調 | `#D6001C` | 瑞士紅，只當點題色 |

### 形狀與層級

- **所有圓角歸零**：卡片、按鈕、輸入框、膠囊卡。瑞士現代主義沒有圓角這種語彙。
- **標題列與按鈕改成平塗**：漸層會讓版面變成「深色主題換成白底」，而不是另一個風格。
- **層級用字重與字級拉開**：Title 20→24、SectionHeader 15→16 並改 Bold；標籤維持小字。
- **區塊標題左側一道 3 px 紅色短規**：整個介面唯一的裝飾，也是這一版最像那個年代的記號。

### 行為上的兩個刻意的選擇

- **啟動固定以淺色（＝瑞士版面）起步**：否則存過深色偏好的機器永遠看不到這次實驗。
  使用者仍可在設定頁切回深色；重開機再回到瑞士版面——測試版的預期行為。
- **強調色八選一照常可用**，預設改為瑞士紅（`#D6001C`）。只有在還沒挑過、仍是預設曦藍時才換；
  自己挑過的顏色不會被奪走。

## 如實申報

- **這是主題層的實驗，不是整站重繪**。版面結構、資訊密度、每一頁的組成沒有動；換的是
  字體、配色、圓角、平塗與一道紅規。若你說「瑞士現代風格」指的是更徹底的重排（網格系統、
  欄位對齊、留白比例），那是另一個量級的工作，這一版沒有做。
- 未在實機上目視驗收：`ThemeSwitchTests` 驗的是「切換後像素真的改變、字色對比達標」，
  不是「好不好看」。
- 全套測試照常跑；`ThemeSwitchTests` 有一條斷言依這一版的設計調整：淺色標題列刻意平塗白、
  不隨強調色著染，著染的行為改在深色主題下驗——契約沒有被拿掉，只是換了位置。
- Release 標記為 **Pre-release**，不會蓋掉正式版的下載位置；主程式視窗標題也加上「測試版」字樣。
