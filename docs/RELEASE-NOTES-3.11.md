# 曦覽 XinSpect 3.11「Swiss」測試版

> **這是實驗版，不是正式版本。** 代號改為 **Swiss**，介面多出第四個主題
> 「瑞士現代主義平面化設計」。合用就留下，不合用整支丟棄——它跑在
> `experiment/swiss-helvetica` 分支，`main` 沒有被動到，正式版仍然是 3.10「Ultima XII」。

## 這一版做了什麼

### 第四個主題：瑞士現代主義平面化設計

不是把淺色主題改掉，而是**獨立的一個主題**（設定頁排在「極限版（東方之星）」之後）：

- **白紙黑墨**：紙面 `#FFFFFF`、主墨 `#000000`、髮絲線 `#D0D0D0`；弱墨 `#6B6B6B` 仍高於 WCAG AA 4.5:1。
- **直角**：卡片、按鈕、輸入框、膠囊卡的圓角全部歸零。其餘三個主題維持原本的圓角——圓角與字級
  改成可換的佈景資源，切換主題時整組換掉，不必重啟。
- **字級整體大一級**：正文 13→14.5、標籤 12.5→13.5、值 13.5→15、區塊標題 15→17、標題 20→24。
- **Helvetica**：拉丁字走 Helvetica（沒有就退 Arial），中文仍由 JhengHei 承接。
- **瑞士紅（#D6001C）只屬於這個主題**：進瑞士版時自動切換，離開時收回曦藍；
  其餘主題不會莫名其妙變成紅色。
- **平塗**：瑞士版的標題列與按鈕不用漸層。
- 區塊標題左側一道 3 px 強調色短規（跟隨強調色，瑞士版就是紅的）。

### 修掉的缺陷

- **AI 評價的「模型：」一直顯示上一台**：工具列直接綁設定裡的 `AiModel`，而共用額度用的是
  Cloudflare Workers AI 的模型（不在那個欄位裡）。現在改走與實際請求同一個解析函式，
  選共用額度就會顯示 Cloudflare 的型號。
- **「檢查更新」永遠是查不到**：匿名呼叫 `api.github.com` 常常直接 403（同一出口 IP 共用額度）。
  新增備援：讀 `/releases/latest` 的 302 轉址取 tag（不經 API、沒有那個額度限制），
  兩條路走同一套版本判定。
- **圓圈問號的「?」在淺色底上消失**：問號顏色在建構時被快取住，換主題後仍是深色主題的淺灰。
  改成跟著佈景資源走，切主題即時更新。
- **內建瀏覽器的起始頁永遠是深色**：起始頁是內嵌 HTML，吃不到 WPF 資源。現在依目前主題著色，
  瑞士版另換 Helvetica 並把圓角歸零。
