# 曦覽 XinSpect 3.11「Swiss」測試版

> **這是實驗版，不是正式版本。** 代號改為 **Swiss**，介面多出第四個主題
> 「瑞士現代主義平面化設計」。合用就留下，不合用整支丟棄——它跑在
> `experiment/swiss-helvetica` 分支，`main` 沒有被動到，正式版仍然是 3.10「Ultima XII」。

## 這一版做了什麼

### 第四個主題：瑞士現代主義平面化設計

不是把淺色主題改掉，而是**獨立的一個主題**（設定頁排在「極限版（東方之星）」之後）：

- **白紙黑墨**：紙面 `#FFFFFF`、主墨 `#000000`、髮絲線 `#D0D0D0`；弱墨 `#6B6B6B` 仍高於 WCAG AA 4.5:1。
- **直角**：卡片、按鈕、輸入框、膠囊卡的圓角全部歸零。其餘三個主題維持原本的圓角——圓角與字級
  改成可換的佈景資源，切換主題時整組換掉，不必重啟。
- **字級整體大一級**：正文 13→14.5、標籤 12.5→13.5、值 13.5→15、區塊標題 15→17、標題 20→24。
- **Helvetica**：拉丁字走 Helvetica（沒有就退 Arial），中文仍由 JhengHei 承接。
- **瑞士紅（#D6001C）只屬於這個主題**：進瑞士版時自動切換，離開時收回曦藍；
  其餘主題不會莫名其妙變成紅色。
- **平塗**：瑞士版的標題列與按鈕不用漸層。
- 區塊標題左側一道 3 px 強調色短規（跟隨強調色，瑞士版就是紅的）。

### 動態：只有一個手勢

這一版的動態刻意收斂成「短規畫出來、內容從下方幾像素淡入」兩件事，沒有回彈、沒有縮放、沒有旋轉：

- **進場**：卡片交錯淡入的時長 360→200 ms、位移 16→8 px；切頁 240→150 ms、10→5 px。
  原本的節奏像「在等動畫演完」，現在只交代東西從哪裡來。
- **區塊標題的 3 px 短規**以 140 ms 由左端長出來；**側欄選取短規**以 120 ms 縱向長滿。
  介面上會動的線只有這一筆——它同時是瑞士版唯一的裝飾。
- 兩者都問 `Motion.Enabled`：設定頁關掉「動態效果」時**直接跳到終點**，不再留半透明的殘影
  （先前只有自繪控制項守這個閘門，進場動畫漏了）。

### 匯出報告重整（動的是內容，不只是版面）

- **順序改成讀者動線**：封面 → 整機摘要 → 系統 → 主機板 → 各件零件 → 量測與證據 → 附錄。
  「系統摘要」（逐域計數那張一千多筆的普查表）原本排在第二節，把第一屏塞滿計數；現在改名
  **「附錄：事實普查」退到最後**。
- **新增五節**：主機板（晶片組＋SMBIOS 擴充插槽＋M.2／U.2＋冷卻裝置）、音訊裝置、風扇（轉速與
  可控風扇兩表）、電池與電源（筆電才有這一節）、NPU（真的偵測到才有）。記憶體多一張**插槽配置**
  表，會列出**空插槽**——只列已裝模組看不出「還有兩個洞」。
- **修掉三個會誤導人的缺陷**：
  1. AI 節把回覆記在**錯誤的模型名下**（選共用額度時仍寫本機 Ollama／自填 API 的型號）；現在與
     實際送出的請求同一個解析結果，並一併標示供應商。
  2. 頁尾一直宣稱「讀不到以『—』表示」，但多數欄位讀不到時輸出的是**空白**；三種格式現在走同一個出口。
  3. 沒讀到時報告會印「**0 MHz**」——0 不是時脈，是沒讀到；同理修掉「**CUDA \*\*\*\***」
     （那是偵測失敗的哨兵值，不是版本號）。
- **刪掉重複**：健康評分不再同時出現在首屏磁貼與整機摘要；風扇讀值不再在「感測器」與「風扇」各列一次；
  主機板欄位從「系統」節搬到「主機板」節。
- **順帶修好事實層的一個顯示缺陷**：單位（筆／條／個）從前無條件接在值後面，句子型的值就變成
  「…188/188 個公開方法都有引用 個」。現在單位只跟純數字，證據實驗室頁面一起變乾淨。
- 報告不再夾帶內部對帳註記（「本筆原本帶了數字…已如實收斂為空」），完整原文仍在證據實驗室。

### 自動判定層的四個誤判（依 04:00 那份報告回報）

- **系統碟判定不再假設「磁碟 0」**：改用 WMI 的邏輯磁碟 → 分割區 → 實體磁碟關聯查；
  查不到時退成「只有唯一一顆放得進 C: 的容量比對」，並在建議與報告裡標明是推測；
  兩者都不可用就誠實寫「未能判定」。回歸案例：C: 在磁碟 3 的 1.2 TB NVMe 上，
  舊邏輯讓它被建議「換一顆 NVMe 當系統碟」——而報告自己讀到 C: 1,117 GB、磁碟 0 只有 931 GB。
  儲存節另加一列**系統碟位置**，讓讀者不必自己猜。
- **磁碟壽命與健康不再互相借名字**：摘要的「67%」是 180 GB SATA SSD 的剩餘壽命，
  「待對映磁區 1」是 ST1000 的 S.M.A.R.T.；從前合成一列、明細只挑其中一顆寫。現在兩件都寫，
  而且各自帶著自己的磁碟名。
- **M.2／U.2 清單只列 NVMe**：SATA 2.5 吋、機械硬碟與 USB 不可能是 M.2／U.2，
  從前它們全被列進「已安裝的 M.2 裝置」。
- **不再宣稱「本機無獨立 GPU（僅虛擬顯示轉接器）」**：那句話是開發機某一刻的狀態被抄進事實文字。
  廠商深層介面沒回值時，現在寫的是「可能是沒有這張卡，也可能是 NVML／ADLX／Xe 不可用，
  兩者都不能讀成這張卡沒有這項功能」——GPU 的溫度、功耗、使用率若在基本讀值裡有值，以那些為準。

### 修掉的缺陷

- **AI 評價的「模型：」一直顯示上一台**：工具列直接綁設定裡的 `AiModel`，而共用額度用的是
  Cloudflare Workers AI 的模型（不在那個欄位裡）。現在改走與實際請求同一個解析函式，
  選共用額度就會顯示 Cloudflare 的型號。
- **「檢查更新」永遠是查不到**：匿名呼叫 `api.github.com` 常常直接 403（同一出口 IP 共用額度）。
  新增備援：讀 `/releases/latest` 的 302 轉址取 tag（不經 API、沒有那個額度限制），
  兩條路走同一套版本判定。
- **圓圈問號的「?」在淺色底上消失**：問號顏色在建構時被快取住，換主題後仍是深色主題的淺灰。
  改成跟著佈景資源走，切主題即時更新。
- **內建瀏覽器的起始頁永遠是深色**：起始頁是內嵌 HTML，吃不到 WPF 資源。現在依目前主題著色，
  瑞士版另換 Helvetica 並把圓角歸零。
