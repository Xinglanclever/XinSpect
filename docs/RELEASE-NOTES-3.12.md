# 曦覽 XinSpect 3.12「Ultima XII」正式版

> **這一版以 3.11 的 Swiss 分支為底座，不是從 3.10 另起一條線。**
> 介面就是 3.11 實驗版驗收過的那一套瑞士現代主義版面：白紙黑墨、直角、Helvetica、
> 瑞士紅短規。3.11 的測試版標記與 Pre-release 標籤在這一版收掉，改為正式發佈。

## 這一版做了什麼

### 一、瑞士現代主義成為正式介面

- 白紙（`#FFFFFF`）、黑墨（`#000000`）、髮絲線（`#D0D0D0`）；次要墨色仍守 WCAG AA 4.5:1。
- 卡片、按鈕、輸入框、膠囊卡的圓角歸零；標題列與按鈕平塗，不用漸層。
- 拉丁字母走 Helvetica（沒有就退 Arial）；中日韓字由 Microsoft JhengHei UI 承接。
- 瑞士紅（`#D6001C`）只屬於這個主題，區塊標題左側的 3 px 短規是介面上唯一的裝飾。
- 原有的深色、淺色、極限版主題都還在，設定頁可切換；切換主題不必重啟。

### 二、核心熱力圖：缺列就留空，不借別顆核心的數字

3.11 已把逐核溫度改成「標籤對位」（`SensorService.CpuCores` 本來就是每實體核心一列，
先前誤以為是逐執行緒而折疊，18 核機器只畫得出 9 格）。3.12 補上缺列防護：

- 某一顆核心沒有對應的感測列時，那一格保留空白。
- 不再退回「按比率折疊」把相鄰核心的數值填進來——寧可留白，也不給一個別顆核心的溫度。

### 三、網卡判讀：三態講清楚，不把「讀不到」寫成「相符」

- PCIe 速度／寬度四個欄位全為 0 時，顯示「PCIe 能力資料未回報」，不再斷言「不是 PCIe 端點」。
- 驅動沒有回報支援速率清單時，顯示「速率能力未回報」，不再判為「鏈路到位」。
- `MediaConnectState` 為 0（未知）時不寫「未連線」——那會叫使用者去查一條沒問題的線。
- 逐網卡事實鍵的末段改為 ASCII（介面名稱先轉 ASCII、再接 8 碼雜湊），
  繁中系統的「乙太網路」也能得到穩定合法的鍵；顯示名稱仍是原來的中文。

### 四、歷史型號查詢（可選、需自行匯入）

- 新增 CPU／GPU 2006–2026 型號索引頁。程式**不內建**任何 workbook 衍生資料，
  目錄只來自使用者明確匯入的 JSON，且不含 NC（CC BY-NC-SA）主機板資料。
- 匯入的資料只留在記憶體，不上傳、不寫入系統；欄位缺漏就留白，不從相鄰型號推測。
- 這一頁回答「這顆型號當年是什麼規格」，不是「你機器上這顆跑得怎樣」——後者看 CPU／主機板／顯示卡頁。

### 五、關於頁的隱藏名言

版本資訊旁有三個很淡的點（`· · ·`），滑鼠移上去會出現提示，點一下展開：

> The sages think themselves to be all-knowing, but we alone are wise to the virtue in those acts of folly.

### 六、發佈資產：四件，逐檔雜湊

| 檔案 | 用途 |
|---|---|
| `XinSpect.exe` | 主程式（便攜單一執行檔） |
| `BlueSquadronBridge.exe` | 藍隊橋接程式 |
| `XinSpectDeploy.exe` | 一鍵安裝器 |
| `SHA256SUMS.txt` | 逐檔 SHA-256 |

安裝器的 GitHub 來源沿用 `releases/latest/download/`（測試釘住「不寫死版本」，
否則舊安裝器會停在舊版）。下載回來的每個檔案先驗 PE 標頭與大小：exe 至少 100 KB、
`.sys` 至少 1 KB，不符就刪掉，不把錯誤頁或確認頁存成程式。

## 已知限制

- 核心熱力圖的混合架構（P-core＋E-core）對位仍以標籤為準；標籤對不上時留空，不做推測。
- 歷史型號頁不含主機板／電源／散熱器資料，也不代為下載任何型號庫。
- Deep Access 的 MMIO 仍走 XsRegProbe；WinRing0 只承擔 MSR／PCI／IO（實測 `ReadMemory` 全數失敗）。
