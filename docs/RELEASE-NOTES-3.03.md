# 曦覽 XinSpect 3.03「Ultima XII」

看得到的地方都修好了：主頁與論壇導航、感測器儀表板復活、M.2／U.2 兩層判定、懸浮小窗 15 項與雙風格，以及一鍵安裝器可以選下載來源（第 301–308 輪）。

## 這一版做了什麼

- **內建瀏覽器**：主頁恢復；導航加上社群論壇（PTT、Chiphell、巴哈姆特、Mobile01、滄者極限、Reddit r/hardware、TechPowerUp 論壇、Overclock.net）與科技媒體（TechPowerUp、AnandTech、Tom's Hardware、iThome、4Gamers）；設定 › 內建瀏覽器可以指定首頁，取代內建的離線導航頁——沒有協定的字串自動補 `https://`，非網頁協定一律視為未設定，不留一個每次按首頁都失敗的設定。
- **感測器儀表板**：修好「點不進去」——建構子不再查歷史倉（檔案被鎖住時整頁會停在建構子裡），歷史倉讀不到時圖表標題直接說「（歷史倉讀不到）」，整頁不再倒下。
- **時間膠囊**：硬碟逐顆讀取失敗的清單拼成一條超過 512 字元的原因字串、導致整份存不了——清單最多列 5 顆、其餘只報數量；快照邊界把超長文字截短並寫出原長；單筆不合格不再讓整份存不了；錯誤訊息改成人話（中文字段名，不再附帶 `(Parameter 'x')`）。
- **GPU 探針**：六支預設探針加上 2.5 秒的外層預算，卡住的驅動不再把整個程式停住；超時說「問不到」，不再把「問不到」講成「沒有這張卡」。
- **M.2／U.2**：改成兩層判定並永遠分開顯示——BIOS 標成型別的是量到的事實；BIOS 只標 PCI Express x4 的另列一張卡並註明是推測；兩者都沒有時如實說「未回報（不代表沒有）」，同時說出本機有幾顆 NVMe。
- **懸浮小窗**：資料項從 7 項增加到 15 項（CPU 功耗／電壓、VRM 溫度、GPU 時脈／風扇／功耗／顯示記憶體、記憶體用量），可逐項關閉、預設全開；可切換曦覽（主題色圓角卡）與微星 Afterburner（OSD：近黑底、紅框、方角、等寬數字）兩種外觀。
- **共用免費額度**：全面開放（自由對話、主動診斷、代理模式都不再需要自備金鑰）；字元預算夾到中轉服務的實際上限 6 萬字元，並用測試直接讀 worker.js 對帳。
- **一鍵安裝器（XinSpectDeploy.exe）**：可以選下載來源——**1** GitHub 最新版（全自動部署主程式＋守護進程）、**2** Google Drive 鏡像、**3** 中國網盤（123 雲盤）分享頁。鏡像連結集中在 `Installer/mirrors.txt`，安裝器啟動時抓一份最新的（3 秒逾時，拿不到就用內建的）；某一格還沒有連結時，選單上如實寫「尚未提供」，按下去會先說明再改用 GitHub。下載完成後一律驗 PE 標頭：分享頁、限流頁、Google 的病毒掃描確認頁被存成 `XinSpect.exe` 會被擋下、刪檔並說出內容像什麼。
- **一鍵評價本機**：移到工具列最左邊（視窗再窄也看得見），簡易模式首頁也加一顆；按下先跳到 AI 分頁再送出。

## 如實申報

- **全套跑綠**：7,361 條全數通過（6 分 51 秒，本機 Debug 組件）。裡面包含 95 個畫面的建構測試，所以本版動過的 UI（感測器儀表板、懸浮小窗的兩種風格、AI 分頁按鈕位置、設定頁新卡片、M.2 卡）至少都真的被建起來過一次。
- **但「建得起來」不等於「看得對」**：外觀、互動與排版仍沒有逐頁在螢幕上看過——那是人類的活。懸浮小窗的 Afterburner 風格尤其需要目視確認字體與行距。
- **硬體數字是這台機器的**：涉及真機讀取的測試（SMBIOS、SPD、NVMe、感測器）讀的是發版這台主機；換一台機器，那些值會不同，這是預期的，不是壞掉。
- **鏡像擱置中**：安裝器的第 2、3 格（Google Drive／123 雲盤）還沒有連結，選單會如實顯示「尚未提供」，按下去會先說明再改用 GitHub。按 1 的官方路徑永遠可用。
