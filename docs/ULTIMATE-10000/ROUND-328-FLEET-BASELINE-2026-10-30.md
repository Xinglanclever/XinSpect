# 第 328 輪（U10 第三圈 EN-0001）：同型號族群基線——「這台與同型不同」在本機看得出來

> 候選項的理由寫得很好：「同一型號換過三台，只有本機基線看得出這台與同型不同」。
> 這一輪把它做出來，並把**三個會讓它變成謊言的東西**先寫死：不上傳、型號是字串相等、
> 樣本不夠就不給 z 分數。

## 一、為什麼要做

`bl.baseline`／`bl.score` 已經是「這台機器跟自己比」的基線：吃歷史倉的時序，回答
「這台比它自己上週熱嗎」。但那個形狀回答不了另一種問題：

> **同一型號換過三台，這台跟另外兩台比起來，有沒有哪一項明顯不同？**

那需要跨快照比對，而跨快照比對只要走錯一步就是「把資料送上雲」。
所以這一輪的第一個設計決定不是演算法，是**邊界**。

## 二、三個先寫死的邊界

### ① 不上傳——這一條是型別層可檢查的

全部計算在本機完成，**只讀本地快照目錄**
（`%APPDATA%\XinSpect\snapshots`，與既有服務同一條慣例）。

不是「先上傳再匿名」，是**根本不連網**。這件事有一條測試守著：
`FleetSnapshotReader.cs` 與 `FleetBaselineFactsService.cs` 兩個檔案裡
**不得出現 `HttpClient`／`WebRequest`／`Socket`** 這幾個字串。

（這個測試在寫的時候抓到一次自己：我在註解裡寫了「連 HttpClient 都不引用」，
於是測試紅了。處置是把那句話改寫成「連任何 HTTP 用戶端型別都不引用」——
守門讀的是檔案內容，註解也算。）

### ② 「同型號」是字串相等，不是產品知識

型號取自快照的 `asset.identify` 值，正規化（壓空白、轉大寫、去全形與標點）後比對。

> 兩台機器「同型號」只代表那兩個字串一樣——不代表同一個 SKU、同一批、
> 或同樣的散熱設計。

正規化**只處理排版**（多一個空白、全形／半形），不動任何語意。

### ③ 樣本不夠就不給 z 分數

少於 `MinSamplesForSpread = 4` 份時，只給**中位數與差值**，不給 z 分數。
理由：兩三個樣本的標準差是裝飾品——它會讓「差 5 度」看起來像「偏離 2.4 個標準差」，
而那個 2.4 是從三個數字算出來的。

標準差為 0 時 z 回 `null`，值裡寫「z 算不出（標準差 0）」，**不印 ∞**。

## 三、比什麼、不比什麼

只比「**每一份都有數值**」的鍵，且只收這幾個前綴下的鍵：

| 前綴 | 為什麼收 |
|---|---|
| `smbios.` | 平台識別與記憶體描述——同型號之間應該接近 |
| `sensor.` | 溫度／風扇／電壓——這是「這台與同型不同」最常出現的地方 |
| `spd.` | 記憶體模組描述 |
| `cpu.` | 處理器與時脈 |

**刻意不收**：裝置清單、事件計數、容量、時間戳。
那些反映「怎麼用」而不是「這台是什麼」——把它們算進來，差異會全部來自使用習慣。

缺一份就不是同一個分母，所以取**交集**；交集為空時值裡寫
「沒有共同的可比數值鍵——沒有共同分母就不比」，而不是印一堆 0。

## 四、排序看的是「離群程度」，不是「變化幅度」

這是這一輪唯一一個容易寫錯的演算法細節。要回答的問題是
**「這台與同型不同」**，所以要把「最新那一份離族群中位數最遠」的鍵排在最前面：

- 有 z 分數時按 `|z|` 排；
- 沒有 z 分數時按 `|差值|` 排。

兩者都用**絕對值**——一個低於族群中位的值同樣是「離群」，不該因為它是負數就沉到最後。

## 五、值裡一定要有的那一句

> 這是**同一台機器不同時間**或**同型號不同台**的快照放在一起比，
> 兩者混在一起時「差異」可能只是時間造成的；
> **本鍵不判讀差異是好是壞**——它只說「離族群多遠」。

本版**不區分**「同一台的不同時間」與「不同台的同一時刻」——因為快照裡沒有可靠的欄位
能分（匿名機器識別是雜湊，同一台會一樣，但「換過三台」的三台是三個不同雜湊，
而「同一台存三次」是三個一樣的雜湊——這件事其實分得出來，但**要不要分**是產品決定，
本版選擇「都放進來、並在界線裡說清楚」）。

## 六、四種「沒有族群」分開講

| 情形 | `Availability` | 寫什麼 |
|---|---|---|
| 本機沒有快照 | `NotApplicable` | 「沒有快照」與「沒有同型號的機器」是兩件事 |
| 有快照但都取不到型號 | `NotApplicable` | 「分不出族群就沒有族群」，不會用全部快照冒充同型號 |
| 每個型號只出現一次 | `NotApplicable` | 「沒有可以比的第二台」 |
| 至少一個型號出現兩次 | `Present` | 逐型號給一份族群事實 |

第二種是這一輪最想防的錯：**把「全部快照」當成一個族群**。
那會讓不同型號的機器互相比較，而結果看起來完全合理。

## 八、怎麼複算

```powershell
# 本機有幾份快照、其中幾份帶得出型號
$dir = Join-Path $env:APPDATA 'XinSpect\snapshots'
if (Test-Path $dir) {
  Get-ChildItem $dir -Filter *.json | ForEach-Object {
    (Get-Content $_.FullName -Raw | ConvertFrom-Json).facts |
      Where-Object { $_.key -eq 'asset.identify' } |
      Select-Object -ExpandProperty value
  } | Group-Object | Sort-Object Count -Descending
}
```

「型號出現兩次以上」才有族群可談——這一行指令的輸出直接就是那一句話的證據。
