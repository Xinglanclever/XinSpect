# 曦覽 XinSpect 3.08「Ultima XII」

雙授權不再只寫在文件裡：關於頁、英文對譯與三份 README 都直接寫明**採雙授權，且適用於所有版本**。

## 這一版修了什麼

3.07 把免責聲明裡那句「嚴禁用於任何商業用途」拿掉了，但沒有把另一句話說完：這份軟體到底是**怎麼**授權的。關於頁只寫「另有商業授權」，讀起來像 AGPL 是預設、商業授權是補充；實際關係是**兩條平行路，二選一**。

這一版把那段話改寫成：

> 本軟體採雙授權（dual licensing），適用於所有版本（不限最新版）：兩條路二選一、功能相同：
> ① AGPL-3.0-or-later——免費，散布修改版或當成網路服務提供時須公開原始碼；
> ② 商業授權——付費，供閉源整合與隨硬體出貨，不觸發原始碼公開義務。

「適用於所有版本（不限最新版）」是這輪的重點，寫在三處：

- `COMMERCIAL-LICENSE.md` 新增**適用範圍**一段：商業授權可以涵蓋你手上的**任何**一個版本，不是只能買最新版。對採購來說這是兩件事——只要最新版，和可以鎖定你已經在用的版本，價格與風險都不同。
- 關於頁與英文對譯（`Services/EnglishStrings.cs`）同步。字串表用中文原文當鍵，中文改字而鍵沒跟著改，英文模式會無聲退回中文；這條由守門釘住。
- 三份 README 的授權段落。

四條新斷言進 `Tests/CommercialLicenseTests.cs`：關於頁要有「所有版本」、文件要有「適用範圍：所有版本」、要有「雙授權」與「dual licensing」，並保留 3.07 那條「不得再宣稱禁止商業使用」。

## 順手補齊的一處證據缺口

在乾淨 worktree 上跑整套時，7,700 條裡唯一紅的那一條是帳本自己的守門 `收口證據必須可回訪`：

```
有 2 條證據路徑在倉庫裡回訪不到（路徑與檔名都找不到）：
U10-UI-0014：lang-livecheck.ps1
U10-UI-0015：lang-find.ps1
```

`docs/ULTIMATE-10000/DEDUP-VERDICTS-2026-10-25.md` 這兩列把收口證據指向兩支腳本，而 `lang-*.ps1` 正在 `.gitignore` 裡（它們是 10 月 8 日的一次性探針）。本機跑得過，是因為檔案還在硬碟上；任何乾淨 clone 都打不開。

處理方式不是把探針硬塞進版控（那是繞過 `/.gitignore` 的本意），而是把證據換成倉庫裡真的有的東西：U10-UI-0014 改指 `LanguageService.Changed` 的四個訂閱者——它們各自在切換語言後重新產生動態文字，這正是那一列要證明的事；U10-UI-0015 只留三支測試檔。

順帶修掉守門自己的一處假紅：路徑正則的每一段原本不允許小數點，WPF 的 `類名.xaml.cs` 只會被抓到尾段 `xaml.cs`，於是**任何**引用 code-behind 的證據都會被判成回訪不到。改成允許內嵌小數點之後，這條守門才真的能驗 code-behind，而不是驗到一個不存在的檔名。
