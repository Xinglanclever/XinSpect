# XinSpect v3.33 ULTIMA XXXIII

2026-11-22。這版加入雙語部署器、貓咪主題和更完整的 CLI 即時監控。下載後可用 `SHA256SUMS.txt` 核對檔案。

## 桌面介面

- 新增「貓貓世界」（繁體）／「吉米国」（簡體）。使用這個主題後可選貓貓語，介面文字句尾加「喵」；主題和語言選擇可保存。
- 貓咪主題下，進入 CPU／GPU 超頻、啟用進階風險功能或啟動深度測試時會先顯示貓咪彈窗。選擇「我就是要你幹」時回應「嘶——！」（繁體）／「哈——！」（簡體）。既有的硬體風險確認仍然適用。
- 關於頁在五行圖旁放入透明底插畫。「這不是我的貓」切換到第二張照片，再按「摸一摸」播放動畫；關閉動態效果時保留首格。第三份附件是單幀 PNG，因此動畫是用該影格製作的版本。三個成品素材合計約 322 KiB。
- AI 協力貢獻表改為按一下展開，標示「據作者統計所排名」；「待定」改成「自然人類」，並註明「由人類和多個 AI 模型協力完成」。
- 移除桌面工具列的「強控台」按鈕，在關於頁新增 XinSpect CLI 入口。東方之星（極限版）及模糊介面中的瑞士主題選項改名 `Ultra`。

## 硬體監控與 CLI

- 核心訪問後端設定移到頁首；新設定檔首次啟動時，可選自動、僅沙箱或允許 WinRing0。選擇只控制經核心後端宿主的呼叫路徑。設定允許 WinRing0 後，讀值仍取決於對應路徑、驅動是否可用以及感測器是否回報資料。
- CPU、GPU、DIMM 頁頂部增加「重新擷取」；CPU 頁分開顯示即時封裝功率來源和 RAPL 驗證狀態。
- 共用路由支援 Windows x64 Intel 的 PawnIO 白名單 MSR 唯讀。使用已安裝的 PawnIOLib 和校驗過的 LHM 內嵌模組；`PLATFORM_INFO` 開啟時試讀不成功或回傳零倍頻，就不加入路由。就緒卡顯示實際後端、試讀及 WinRing0 未能開啟的原因。
- `top` 顯示 GPU 溫度、GPU 使用率、顯存用量、系統記憶體使用率及容量。依終端可見欄寬排版，無法同列容納的欄位會換行。
- CLI 的 `sys`、`dash`、`top` 顯示 CPU 封裝功率和來源。LHM 上報值會標成「未驗證」，不寫入已驗證功率的歷史；讀不到數據或 RAPL 已確認不隨負載變化時仍顯示 `——`。被動監控不會啟動負載測試。
- CLI 在空提示符按 `K` 可在英文和簡體中文之間往返；介面與 `shortcuts` 都有提示。語言命令改用 `lang zh-T`、`lang zh-S`，也可執行 `lang en`。
- CLI 預設迎賓使用旋轉地球與 Global Village。終端狀態列第一行顯示 `Winring0.sys`，下一行只保留分隔線。

## 部署器

- `XinSpectDeploy.exe` 顯示英文；`XinSpect部署器.exe` 預設繁體中文，並以簡體中文提示「按 K 切换到简体中文」。GitHub 請下載 `XinSpectDeploy-zh.zip` 並解壓，Google Drive 可直接下載中文檔。選單按 `~` 回上一層。
- 無法取得校驗清單時，`Y` 將未驗證的檔案另存到桌面上的獨立資料夾，`N` 結束，`K` 回下載來源選單。校驗值存在但檔案不符時，仍會拒絕該檔案。
- 檔案大小上限改為 128 KB（131,072 bytes）。兩個本機候選檔各為 62,976 bytes，SHA-256 相同，仍由系統的 .NET Framework 執行。
