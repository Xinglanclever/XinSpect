# 曦覽 XinSpect 3.07「Ultima XII」

免責聲明改成與授權一致：拿掉「嚴禁用於任何商業用途」。關於頁最上面多了一行品牌標語。

## 這一版修了什麼

程式與三份文件原本都寫著同一句話：

> 本軟體為免費開源軟體，可自由下載、使用與散布，**並嚴禁用於任何商業用途**。

那是 AGPL 之前的說法，留到今天變成一句自相矛盾的話：專案以 **AGPL-3.0-or-later** 釋出，而 AGPL 明文允許商業使用；`COMMERCIAL-LICENSE.md` 賣的正是「不想公開原始碼的閉源整合」。兩句並存，等於告訴使用者「可以買授權，但你不准用」。

同一句話在四處一起改寫（關於頁的免責聲明、說明目錄、英文對譯、README 的說明目錄）：

- 可自由下載、使用、研究、修改與散布，**包含商業使用**；
- 若散布修改版，或把它當成網路服務提供給他人使用，須以相同授權公開原始碼；
- 無法採用 AGPL 的閉源整合，另有商業授權。

兩條新守門：程式內不得再出現「嚴禁……商業使用」的字樣；英文譯文必須以新的中文原文為鍵——字串表用中文原文查表，中文改字而鍵沒跟著改，英文模式會悄悄退回中文，不會紅、也不會有人發現。

## 關於頁的品牌標語

```
Designed in East Asia
Manufactured for the World
```

放在「曦覽 XinSpect」標題正下方、版號之前，16 px 半粗、強調色——比內文（13–13.5）大一圈，但刻意遠小於標題的 30。它是署名，不是主標。

原文就是英文，不進翻譯表：這一句在中文模式與英文模式都該長這樣。守門釘住三件事——存在、在版號之前、字級落在 14–17（「大一圈」不等於「放大成標題」）。
