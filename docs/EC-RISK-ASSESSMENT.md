# WP31：EC（Embedded Controller）唯讀存取風險評估記錄

- **狀態**：評估完成——**未評估通過前不出貨**（與 ROADMAP-G6 的裁定一致）。
- **結論**：即使用戶態程式只「讀」EC（I/O 埠 0x62／0x66），在 Windows 上仍屬**高風險操作**，
  與 Windows ACPI 驅動（acpi.sys）的交易排程存在實質衝突面。本工具**不實作**任何 EC 埠存取；
  未來若有安全通路（核心過濾驅動與 acpi.sys 合作、或廠商 WMI 直通），再依本文件重評。
- **評估日期**：2026-10-03（ITER44 R3）
- **評估人**：XinSpect 自動化迭代（供作者複核）

## 1. 通路與所有權現況

| 通路 | 說明 | 所有權 |
|---|---|---|
| I/O 0x62（EC_SC）／0x66（EC_DATA） | ACPI 規範的 Embedded Controller 介面（ACPI 規格 ch.12）：狀態埠的 IBF／OBF／BURST 旗標＋命令／資料埠 | **acpi.sys 獨占**：電池（CMBatt）、熱區（AcpiTimer／Thermal）、ACPI OperationRegion（EmbeddedControlled）全走它 |
| OperationRegion（EC 欄位） | ASL 透過 `OperationRegion(..., EmbeddedControlled, ...)` 存取 EC RAM | 同上——由 acpi.sys 序列化 |
| 廠商 WMI（若有） | 部分主機板／筆電暴露 `_SB.PCI0.LPCB.EC0` 的 WMI 方法 | 由驅動代轉，安全 |

關鍵事實：**EC 交易是全機共用的串列協定**。任何一方在錯的時機送出 RD_EC／WR_EC 命令、
或在對方交易中途讀走 OBF 的資料位元組，就會讓兩邊的「第 N 位元組」錯位——
接收方拿到的是下一筆交易的資料。錯位不是「讀到舊值」，是**讀到別筆交易的值**。

## 2. 「只讀不寫」為什麼仍然危險

1. **命令埠就是寫入**：EC 的「讀」是先向 0x66 寫入 RD_EC(0x80)＋偏移位址，再從 0x62 讀資料——
   所謂唯讀查詢實際上包含對 EC 的兩次寫入與一次讀取，不存在「純讀」的 EC 存取。
2. **狀態旗標競爭**：IBF（輸入緩衝滿）／OBF（輸出緩衝滿）是兩方共用的單位元旗標。
   使用者態輪詢 0x62 這個動作本身無害，但接著的命令寫入若與 acpi.sys 的交易交錯，
   可能清掉對方等待中的旗標或讓對方讀走我方的資料位元組。
3. **BURST 模式**：acpi.sys 以 burst（0x20/0x21 命令）批次交易以減少 EC 打斷次數；
   在 burst 中途插入交易會直接破壞批次序。
4. **EC RAM 並非全是感測器**：部分偏移是「寫才有效」的控制位（風扇 PWM、充電閾值、
   韌體旗標）。RD_EC 本身安全，但解讀錯偏移而後續擴展成 WR_EC 的滑坡風險真實存在——
   本工具的設計紀律是連第一步都不踏出。
5. **讀壞不當場爆**：EC 錯位的症狀常是**延遲顯現**（風扇失控、電池不充電、熱保護誤觸發），
   對「硬體檢查工具」而言，造成機器不穩定即是本末倒置。

## 3. 風險矩陣（唯讀情境）

| 情境 | 可能性 | 後果 | 等級 |
|---|---|---|---|
| 與 acpi.sys 電池／熱輪詢交易交錯 | 高（持續背景輪詢） | 兩方資料錯位 | **高** |
| burst 批次中插入交易 | 中 | 批次序破壞、EC 重置 | **高** |
| 讀到「讀取觸發」型偏移（少見但存在） | 低 | 副作用事件 | 中 |
| SMM／SCI 同期競爭 | 低 | 系統事件遺失 | 中 |

## 4. 決策與重開條件

- **決策**：不實作 EC 埠存取。工作包 WP31 以本記錄結案（替代 WP31 原訂的「EC 唯讀感測器讀取」）。
- **重開條件**（需同時成立並經作者明確同意）：
  1. 存在與 acpi.sys 合作的核心端通路（過濾驅動掛 `ACPI\PNP0C09` 之下序列化交易），或
  2. 平台暴露廠商 WMI／ASL 方法可安全取得同一批感測值，且
  3. 有測試機可長期驗證（電池充放電循環＋熱輪詢並行下的穩定性）。
- **本機可得的 EC 相關事實**（不經 EC 埠）：電池狀態經 `Win32_Battery`／`BatteryStatus`（WMI，
  acpi.sys 代轉）已足；風扇轉速若 SuperIO 提供（WP17）走 SuperIO 晶片自己的 HWM 暫存器，不經 EC。
