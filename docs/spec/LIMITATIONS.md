# XinSpect 公開限制（Limitations）

- **原則**：限制要寫在使用者看得到的地方。這份清單與程式內的三態標示同一套裁決——有機器對帳的不寫錯。

## 已明文不實作（設計裁決，不是遺漏）

1. **EC（Embedded Controller）埠存取**——「唯讀」實含命令埠寫入，與 acpi.sys 的交易排程有實質
   衝突面。風險評估記錄與重開條件見 `docs/EC-RISK-ASSESSMENT.md`。
2. **Rowhammer 抗性驗證未實作**——現有 GUI／服務只提供未經校驗的 usermode 記憶體壓力探測，
   不保證觸發 Rowhammer，也不能證明抗性；相鄰實體列無法隔離，可能損壞其他處理程序資料。
   需專用機器、依序啟用兩級風險開關及每次操作明確同意；還原寫入許可不能授權壓力測試。
   關閉任一開關會在後續配置／worker／壓力區段檢查點拒絕繼續；這是合作式停止，並非即時硬取消。
   GUI 消耗本次勾選，操作結束與重開開關均不恢復同意或自動重啟。CLI 目前沒有此入口。
3. **IPMI 帶外管理通路**（KCS／SSIF／NCSI）——本機無 BMC 無法驗證；只做 SEL／FRU／SDR 的
   **訊息解碼**，不宣稱支援 IPMI 本身。
4. **MegaRAID BBU／VD／PD／foreign config 佈局**——文獻版本分歧、無硬體可逐項確認；只解
   MFI 訊框標頭的跨實作一致欄位。
5. **MCHBAR 記憶體時序（tCL/tRCD/tRP/tRAS）**——MRC 訓練結果區，Intel 公開 datasheet 未定義；
   社群逆向不合本工具門檻。
6. **PCH 世代名稱對照**——LPC DID→行銷名需逐檔交叉對準出處；未對準不出值。
7. **Registry.pol 二進位解析**——只回報機器原則檔的存在與寫入時間指紋。

## 已知能力邊界

8. **PCI BAR 大小不出值**——大小需要寫入探測（寫全 F 讀遮罩），本工具對 PCI 設定空間唯讀。
9. **Wi-Fi 連線態欄位（RSSI／頻道／BSSID）**——介面未連線時如實標「未連線」，不猜。
   頻道來自 BSS list 中心頻率的查表換算；頻率落在等差之外回 null。
10. **CPU 世代對照表只收錄有把握的子集**——未收錄的 model 如實標「未收錄」；
    錯誤的世代標示比沒有更糟。
11. **突變測試只覆蓋純解碼器**——主專案（WPF＋特權通路）的突變面由注入式測試與金標向量承擔。
12. **快照雜湊是完整性信封不是數位簽章**——只能偵測檔案被改動，不能證明出自本工具。

## 環境相依

13. **HVCI／VBS 開啟時**：MSR 可能被攔截或回假值、TSC 可能被偏移——所有 MSR 卡片的可信度
    打折（平台可信度頁明示本機狀態）。
14. **微碼登錄檔佈局變體**：Update Revision 有 8 位元組與 4 位元組兩種實測佈局；
    兩者都解碼並註明變體，雙 DWORD 皆非零的歧義如實標「不解碼」。

15. **CMOS／RTC 原始埠讀取**：一般 WinRing0 後端未建立與 OS／韌體協調的 0x70/0x71 與 NMI 所有權；本版回 `NotSupported`，不表示沒有 RTC 硬體。具有協調所有權的後端仍須通過既有兩級風險閘門，只可讀取已定義的無清旗標副作用地址，禁止讀 0x0C。RTC 時鐘須在有界預算內取得前後 UIP／格式一致的雙樣本，無法建立一致性則回 `ReadError`；不宣稱排程可保證 244µs 或已完成實機安全驗證。

## R386 CLI 記憶體設定速率範圍

`memory.rate` 的 CLI WMI 來源是 Windows 回報的設定資料速率；不是控制器即時時脈或目前主時序。
所有列完成且設定速率一致才發布 Present；缺值／混速／空集合維持 Unknown，部分失敗不以剩餘列推定全機速率。
沿用既有混插查詢並擴充欄位，沒有第二次 WMI 查詢或 CPU-Z／SPD 啟動。
WMI 提供者可能仍在呼叫端逾時後執行；同一路徑在其真正完成前不重發、不提前處置資源，晚到結果不得發布。
此範圍不新增 `memory.current` 的 CLI 來源，也不宣稱真實硬體精準度或全平台相容性。
