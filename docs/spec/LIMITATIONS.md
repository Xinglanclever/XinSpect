# XinSpect 公開限制（Limitations）

- **原則**：限制要寫在使用者看得到的地方。這份清單與程式內的三態標示同一套裁決——有機器對帳的不寫錯。

## 已明文不實作（設計裁決，不是遺漏）

1. **EC（Embedded Controller）埠存取**——「唯讀」實含命令埠寫入，與 acpi.sys 的交易排程有實質
   衝突面。風險評估記錄與重開條件見 `docs/EC-RISK-ASSESSMENT.md`。
2. **Rowhammer／記憶體攻擊面施測**——會弄壞東西。只標風險與 ECC 現況；施測需專用機器＋明確同意。
3. **IPMI 帶外管理通路**（KCS／SSIF／NCSI）——本機無 BMC 無法驗證；只做 SEL／FRU／SDR 的
   **訊息解碼**，不宣稱支援 IPMI 本身。
4. **MegaRAID BBU／VD／PD／foreign config 佈局**——文獻版本分歧、無硬體可逐項確認；只解
   MFI 訊框標頭的跨實作一致欄位。
5. **MCHBAR 記憶體時序（tCL/tRCD/tRP/tRAS）**——MRC 訓練結果區，Intel 公開 datasheet 未定義；
   社群逆向不合本工具門檻。
6. **PCH 世代名稱對照**——LPC DID→行銷名需逐檔交叉對準出處；未對準不出值。
7. **Registry.pol 二進位解析**——只回報機器原則檔的存在與寫入時間指紋。

## 已知能力邊界

8. **PCI BAR 大小不出值**——大小需要寫入探測（寫全 F 讀遮罩），本工具對 PCI 設定空間唯讀。
9. **Wi-Fi 連線態欄位（RSSI／頻道／BSSID）**——介面未連線時如實標「未連線」，不猜。
   頻道來自 BSS list 中心頻率的查表換算；頻率落在等差之外回 null。
10. **CPU 世代對照表只收錄有把握的子集**——未收錄的 model 如實標「未收錄」；
    錯誤的世代標示比沒有更糟。
11. **突變測試只覆蓋純解碼器**——主專案（WPF＋特權通路）的突變面由注入式測試與金標向量承擔。
12. **快照雜湊是完整性信封不是數位簽章**——只能偵測檔案被改動，不能證明出自本工具。

## 環境相依

13. **HVCI／VBS 開啟時**：MSR 可能被攔截或回假值、TSC 可能被偏移——所有 MSR 卡片的可信度
    打折（平台可信度頁明示本機狀態）。
14. **微碼登錄檔佈局變體**：Update Revision 有 8 位元組與 4 位元組兩種實測佈局；
    兩者都解碼並註明變體，雙 DWORD 皆非零的歧義如實標「不解碼」。
