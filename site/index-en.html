READ-ONLY HARDWARE FACTS ・ v3.26 ULTIMA XXVI

Hardware facts,
not stories.

XinSpect is a read-only hardware fact collector for Windows: 1,178 catalogue keys across 157 domains, including hardware, OS, security, diagnostics, and provenance; these are not 1,178 hardware readings. There are also 69 dynamic families. If it can read a value, it reports it; if it can't, it says so — it never invents one. Single executable, no install, bundled with a Claude-Code-style terminal called xsc.

FAQ

straight answers only
Will it touch my hardware? Can it break anything?
Fact collection is strictly read-only: PCI scan, MSR reads and firmware parsing write nothing. Overclocking-style writes are not on the default path — hardware writes require the second security tier plus per-item confirmation, and every write is automatically logged (the CLI can report the ledger).
Why do some pages show only "—"?
Nothing is broken. The app starts with normal privileges (asInvoker, least privilege); sensors, direct MSR reads and overclocking pages need "Run as administrator". Without elevation those pages honestly show "—" with reasons — that is the six-state degradation design doing its job: unreadable means unreadable, never zero-filled, never invented.
Does it phone home? Is anything uploaded?
Hardware fact collection happens entirely on the machine, with no network. The AI page is optional and uses Cloudflare Workers AI with your own API key — the key is encrypted with Windows DPAPI before it is written to settings.json; if it can't be decrypted you get "no key + reason", never plaintext on disk.
How do I install and upgrade?
Download the 29 KB XinSpectDeploy.exe (see Download above): A for the GUI app, B for the terminal, three switchable sources. Upgrades go through the same deployer — its mirror list is fetched fresh at every launch, so you always get the latest build.
Is it free? Can I use it commercially?
Dual licensing with identical features: AGPL-3.0-or-later is free, including commercial use (distribute modified versions or offer it as a network service and you must share source under the same license); closed-source integration, bundling with hardware, or copyleft-hostile organizations use the commercial license. Details in the licensing section below.
Which systems are supported?
Windows 10 1903+／Windows 11, x64. Self-contained builds need no .NET install; the terminal also ships a plain-console build for Windows Server 2016, 2019 and 2022.

Security & privacy

boundaries stated in the open

Read-only guard

references no write path

Guard tests pin fact collection to "references no write path"; the XsRegProbe kernel driver is whitelist read-only (MSR／MMIO) and was rated the only "excellent" in the internal audit.

Write ledger

every write logged automatically

Operations that actually write hardware are off the fact path: every write is logged automatically and the CLI can report the ledger; writes additionally require the second security tier and per-item confirmation.

Least privilege

asInvoker ・ no hidden elevation

The app starts with normal privileges; elevation is an explicit decision, never a hidden one. Components that shouldn't hold an admin token (WebView2, AI) are kept on the low-privilege side.

Local encryption & integrity

DPAPI ・ SHA-256

AI API keys are DPAPI-encrypted before touching disk; downloads always pass PE header and size-floor checks; per-asset SHA-256 lives in the Release's SHA256SUMS.txt. Publisher signing (non-repudiation) is honestly listed as scheduled, not pretended.

Found a security issue? Please use the private channel in SECURITY.md — the only entry guaranteed to stay private.
