常見問題

FAQ ・ 有什麼答什麼
它會動我的硬體嗎？會寫壞嗎？
事實採集全程唯讀：PCI 掃描、MSR 讀取、韌體面解析都不寫入。超頻等真正寫硬體的功能不在預設路徑上——底層功能依雙級安全設定開啟，硬體寫入另需第二級安全與逐項確認，且每次寫入自動記帳（CLI 可申報）。
為什麼有些頁面整片顯示「—」？
不是壞掉。程式預設以一般權限啟動（asInvoker 最小特權）；感測器、MSR 直讀與超頻需要「以系統管理員身分執行」。不提權時那些頁面如實顯示「—」並標明原因——這正是六態降級設計（Present／NotSupported／InsufficientPrivilege 等）存在的理由：讀不到就說讀不到，不補 0、不編值。
會連網嗎？資料會上傳嗎？
硬體事實採集全部在本機完成，不連網。AI 頁為選用功能，走 Cloudflare Workers AI，需要你自己的 API 金鑰——金鑰以 Windows DPAPI 加密後才寫進 settings.json，解不開就是「沒有金鑰＋原因」，不會明文落盤。
怎麼安裝、怎麼升級？
下載 29 KB 的 XinSpectDeploy.exe（本頁下載節），A 裝主程式、B 裝終端機，三個來源可切換。升級同樣走部署器——鏡像清單每次啟動自動抓取，永遠拿到最新版。
免費嗎？商業使用可以嗎？
雙授權、功能完全相同：AGPL-3.0-or-later 免費，包括商業使用（散布修改版或以網路服務提供時須開源）；閉源整合、隨硬體出貨、禁 copyleft 的組織走商業授權。細節見下方授權節。
支援哪些系統？
Windows 10 1903 以上／Windows 11、x64。帶環境版免裝 .NET 10 Desktop Runtime；曦覽終端機另有純文字相容版，支援 Windows Server 2016、2019、2022。

安全與隱私

SECURITY ・ 邊界寫在明處

唯讀守門

不引用任何寫入通路

守門測試限制事實採集不引用硬體寫入通路；XsRegProbe 以白名單限制 MSR／MMIO 讀取。本次修正其 MMIO 頁面保護旗標。現有審查屬 AI 輔助的內部檢視，不是獨立第三方安全審計。

寫入稽核

每次寫入自動記帳

真正會寫硬體的操作不在事實路徑上：每次硬體寫入自動記帳、CLI 可申報；超頻等寫入另需第二級安全與逐項確認。

最小特權

asInvoker ・ 不吃管理員令牌

預設以一般權限啟動；提權是顯式決定而非隱藏行為。WebView2、AI 等不該吃管理員令牌的元件被擋在小特權側。

本機加密與完整性

DPAPI ・ SHA-256

AI API 金鑰以 Windows DPAPI 加密後才落盤；部署下載一律驗 PE 標頭與大小門檻，逐資產 SHA-256 見 Release 的 SHA256SUMS.txt。發佈者簽章（不可否認性）已列入排期，如實公告而非假裝已有。
