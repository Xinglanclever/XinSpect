事實系統

第一層 ・ 部署什麼

A / B 二選一

A — XinSpect.exe 主程式（GUI）
65 頁硬體事實、強控台、合規出口。全自動部署主程式＋藍色中隊守護進程；守護進程自 3.13 起預設不啟用，裝完可到安全頁自行開啟。

B — 曦覽終端機 xsc
Claude Code 式 REPL＋全螢幕 dash，單檔下載一步到位，不需要 GUI 也能操作全部事實面。

兩維版本任選：帶環境（self-contained，.NET 10 Desktop Runtime 一併打包，免裝執行階段，體積較大）／不帶環境（framework-dependent，機器需已裝 .NET 10 Desktop Runtime，體積較小）。

第二層 ・ 從哪裡下載

1 / 2 / 3 三個來源

1 — GitHub
releases/latest 直連，全自動部署主程式＋Bridge，海外網路首選。

2 — Google Drive 鏡像
latest/ 資料夾就地覆寫、永遠最新；遇到 Drive 對 exe 的「無法掃描病毒」攔截頁，安裝器會自動改走直連重試。

3 — 加速節點（中國大陸）
第三方節點以分享頁方式開啟。注意：走加速節點拿到的位元組只能驗 PE 標頭，驗不了發佈者簽章。

下載完之後 ・ 安裝器的安全檢查

每個位元組都先驗再落地

下載過程顯示進度條、速度與剩餘時間；完成後一律檢查 PE 標頭與大小門檻——抓到 HTML（分享頁、限流頁）會被擋下、刪檔，並如實說出抓回來的內容像什麼，不會把垃圾存成 exe。

系統需求：Windows 10 1903 以上／Windows 11、x64。帶環境版免裝 .NET；不帶環境版需先裝 .NET 10 Desktop Runtime。

權限：主程式預設以一般權限啟動（asInvoker 最小特權）。想取得感測器、MSR 直讀與超頻頁面的完整功能，請「以系統管理員身分執行」——不提權不是壞掉，那些頁面會整片如實顯示「—」（六態降級設計存在的理由）。

完整性：逐資產 SHA-256 見 Release 頁的 SHA256SUMS.txt（防傳輸損毀）。
