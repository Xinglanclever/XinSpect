# 曦覽終端機 XinSpect Console — 分支預覽版

> 此版本由分支 [`release/xinspect-console`](https://github.com/Xinglanclever/XinSpect/tree/release/xinspect-console) 發佈，內容為**曦覽終端機**（原 xsc）的介面全面翻新，主程式 XinSpect.exe 不受影響。

## 終端機介面

- **CLI 開場**：大字 XINSPECT（ANSI Shadow 圓角體）＋ `by: xinglanclever` 標註＋ `☼` 品牌符號
- **雙欄歡迎框**：Welcome back! ＋ 快速開始（真實指令集）＋ 小知識 ＋ cwd
- **框線系統重構**：新增 BoxTop／BoxBot／BoxRow／BoxTwoCol 通用 helpers——角與右框線一律 CHA 絕對定位，終端解析度與字型差異不再造成錯位或折行
- **輸入框**：上下兩條長線＋紅色 `>` 提示符＋右下角狀態行

## 狀態行（右下角）

`● 權限 · ring0 狀態`——全部真實偵測：

- **權限**：SYSTEM（SID S-1-5-18）／administrator／標準權限
- **ring0**：登錄檔查 WinRing0／XsRegProbe 服務機碼；查無如實標「未註冊」，不編造就緒

## 指令書與百科全書

- **help**：分類功能表（採集查詢／即時監控／深層探針／證據合規／導覽／系統，23 指令）＋ `help <指令>` 單頁詳解
- **book**：整本曦覽百科（15 部 362 節）離線嵌入——`book` 目錄、`book 6` 部清單、`book 6.3` 節全文、`book 關鍵字` 搜節標題

## 採集體驗（借部署器經驗）

- 破曉序列 spinner：`∙∘○◎☼` 往返＋14 個繁中採集動詞
- 掃描式進度條＋即時計時
- **示波器線**：真實 CPU 負載取樣畫 `▁▂▃▄▅▆▇█` 波形（PerformanceCounter；不可用時整行略過，不造假波形）
- 完成輸出 `⏺ facts (1,178 靜態鍵 · 69 動態家族 · 耗時 Ns)` ＋ `⎿` 結果行

## 穩定性

- **REPL 永不崩**：主迴圈與按鍵迴圈全部 try/catch——任何控制台 IO／句柄例外攔下顯示後繼續，使用者絕不被踢回 cmd 提示符
- **即時 resize 重繪**：拖動窗口時整個界面跟著重排（清掉捲動歷史，即時重繪的必要取捨）
- spinner 後台執行緒全面防護
