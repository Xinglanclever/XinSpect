# 附錄

本附錄的全部內容由 `work/wp_gen.py` 掃描本版原始碼產生（詞彙表除外），指令為：

```
python work/wp_gen.py
```

產生器輸出的分割檔位於 `work/wp/`，並由組裝腳本依序串接為本文件。因此附錄與程式碼之間不會漂移：若程式碼中的鍵、規則、豁免或模組發生變更，重跑產生器即可得到對應的附錄，且差異可逐行比對。

各附錄的對應來源如下：

| 附錄 | 內容 | 來源 |
|---|---|---|
| A | 靜態事實鍵全目錄與其產生模組 | `Services/FactKeyCatalog.cs`、`Services/*.cs` |
| B | 動態鍵家族與其成員決定方式 | `Services/FactKeyDynamicCatalog.cs` |
| C | 對帳規則索引 | `Services/VerifyRules.cs` |
| D | 明文豁免清單與理由 | `Services/FactCoverageReport.cs` |
| E | 服務模組索引 | `Services/*.cs` |
| F | 測試檔索引 | `Tests/*.cs` |
| G | 文件索引 | `docs/**/*.md` |
| H | 詞彙表 | 人工撰寫 |

附錄 A 至 G 的表格中，「產生模組」與「擁有鍵數」兩欄的定義為：該模組的原始碼中含有對應事實鍵的字串常值。一個鍵可能由多個模組引用（例如讀取端與呈現端），此欄列出全部引用者；一個模組的「擁有鍵數」為其引用的鍵數總和，因此總和會大於鍵的總數。
